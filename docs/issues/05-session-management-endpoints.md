# #05 — Gestão de sessões

## Objetivo
Dar ao usuário e ao administrador controle sobre sessões ativas.

## Endpoints previstos
- Listar sessões do usuário.
- Revogar sessão específica.
- Revogar demais sessões.
- Revogar todas as sessões administrativas conforme política.

## Aceite
- Usuário não revoga sessão de outra pessoa.
- Dispositivo atual é identificado sem expor token.
- Eventos de revogação são auditados.
